# Yeastdonkey Resource Pack

This is a custom Minecraft resource pack derived from [VanillaTweaks](https://vanillatweaks.net/) modules, with additional aesthetic and utility enhancements curated for the Yeastdonkey modpack. It refines Minecraft’s visuals and interface while maintaining the core vanilla style.

## ✨ Features

- Sourced from [VanillaTweaks](https://vanillatweaks.net/)
- Improved block/item clarity and UI consistency
- Enhanced visibility for important gameplay elements
- Faithful to the vanilla aesthetic
